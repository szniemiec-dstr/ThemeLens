# Name and logo

"ThemeLens" is a working title and has not yet been checked for trademark conflicts.

The GPL covers the code. It does not cover the project's name or logo. Forks are welcome, but please do not
distribute a modified version under the ThemeLens name or with its logo, so that people can tell which build
they have. Saying that your project is "based on ThemeLens" is fine.

This policy will be finalised together with the name.
